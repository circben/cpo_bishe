# 第七章 可视化系统设计与实现

---

## 7.1 可视化需求与设计目标

大型语言模型的搜索式推理过程包含丰富的可分析信息——树结构拓扑、路径分支、节点评分分布、各基线性能差异、超参数敏感性等。然而，现有工作在可视化方面以静态表格和示意图为主，缺乏交互式探索能力，研究者难以直观理解搜索行为和训练动态。

本课题构建的Web可视化平台旨在提供以下分析能力：

1. **思维树结构浏览**：交互式查看每个问题的完整搜索树，展示节点生成、评分、剪枝全过程。
2. **多基线性能对比**：在同一仪表盘中对比SC-ToT、CoT、TS-SFT、CPO的准确率和推理延迟。
3. **统计分析查询**：按数据集、模型、超参数配置等维度聚合分析实验结果。
4. **消融分析视图**：可视化关键超参数的消融曲线，辅助理解各设计选择的影响量级。

---

## 7.2 系统架构

可视化系统采用前后端分离的B/S架构：

```
浏览器 (D3.js + HTML/CSS)
    ↓ HTTP/WebSocket
FastAPI后端 (Python)
    ↓ 文件读取
Stage 2搜索树JSON + Stage 4评估结果JSON
```

**后端层**：由`scripts/stage5/web/run_stage5_api_server.py`启动FastAPI服务，提供RESTful API。API路由包括：
- `/api/trees`：获取所有问题的搜索树列表
- `/api/tree/{id}`：获取特定问题的完整搜索树JSON
- `/api/performance`：获取各方法在各数据集上的性能指标
- `/api/stats`：获取聚合统计信息
- `/api/ablation`：获取消融实验数据

后端从Stage 2输出的序列化树文件和Stage 4输出的评估结果JSON中读取数据，经格式化后以JSON返回前端。

**前端层**：由四个独立HTML页面和共享的D3.js v7库（`d3.v7.min.js`）组成。页面间通过`index.html`导航页连接。由于所有数据来自后端API，前端无需预处理，直接进行可视化渲染。

**远程访问**：`scripts/stage5/start_local_tunnel_and_api.ps1`脚本结合bore内网穿透工具，将本地FastAPI服务暴露到公网，供远程协作查看。

## 7.3 思维树浏览器

思维树浏览器（`tot_viewer.html`）是可视化平台的核心模块，提供搜索树的三维探索。

### 7.3.1 树布局与渲染

使用D3.js的树布局（`d3.tree()`）将搜索树绘制为从上到下的层级结构。每个节点表示为一个圆形或矩形，其属性映射到视觉编码：
- **节点大小**：映射到综合评分，高分节点视觉更大
- **节点颜色**：绿色表示路径节点（成功路径上的节点），红色表示被剪枝节点，灰色表示中间节点
- **边样式**：实线表示父子关系，虚线表示剪枝关系

布局算法自动计算节点的水平间距以避免重叠，纵向间距反映树的深度层级。

### 7.3.2 交互功能

浏览器提供以下交互操作：
- **缩放与平移**：通过鼠标滚轮和拖拽自由缩放和移动树视图，适应不同规模的搜索树。
- **节点悬停提示**：鼠标悬停在节点上显示Tooltip，包含节点ID、推理文本摘要、步骤评分、状态评分和综合评分。
- **节点展开/折叠**：点击节点可展开或折叠其子树，便于聚焦关注区域。
- **路径高亮**：选择某条成功路径后，路径上所有节点和边以醒目颜色高亮显示，其余部分降低透明度。
- **问题选择器**：顶部下拉菜单切换不同问题，后端异步加载对应搜索树。

### 7.3.3 搜索树数据模型

前端接收的搜索树JSON结构如下：

```json
{
  "question_id": "gsm8k_train_001",
  "question_text": "Janet在商店买了...",
  "root": {
    "id": "n0",
    "state": "...",
    "depth": 0,
    "score": 1.0,
    "step_score": null,
    "state_score": null,
    "is_terminal": false,
    "is_on_path": true,
    "children": [...]
  }
}
```

每个节点包含完整的递归子节点数组，前端通过D3的`d3.hierarchy()`将其转化为层次结构数据。

## 7.4 性能对比仪表盘

性能对比仪表盘（`performance_viewer.html`）提供多方法性能的直观对比。

### 7.4.1 对比视图

仪表盘包含三个并排面板：

**准确率条形图**：X轴为方法（CoT、SC-ToT、TS-SFT、CPO），Y轴为准确率百分比。不同数据集用不同颜色区分。每个条形上方标注具体数值。

**延迟散点图**：以方法为分组，每个点代表一个问题，Y轴为该问题的推理延迟（秒）。通过箱线图展示各方法的延迟分布。

**效率比（准确率/延迟）**：将准确率与延迟归一化后计算效率比，横向条形图清晰展示CPO在效率维度上的优势。

### 7.4.2 数据集切换

顶部选项卡可在GSM8K和StrategyQA之间切换，所有图表联动更新。支持悬停查看精确数值、点击高亮特定方法、导出图表为PNG。

## 7.5 统计报告页面

统计报告页面（`statistics_report.html`）提供实验数据的多维度聚合统计。数据由`scripts/stage5/visualize_stats.py`预计算并通过API提供。

### 7.5.1 搜索统计

展示SC-ToT搜索的聚合统计指标：
- 平均搜索深度、平均节点数、平均成功路径数
- 剪枝率（被剪枝节点占比）、束利用率
- 评分分布直方图（展示所有被评估节点的评分分布）

### 7.5.2 训练统计

展示CPO/TS-SFT训练过程的监控指标变化：
- DPO损失曲线（训练集损失和验证集损失）
- chosen/rejected对数概率差值曲线
- TS-SFT交叉熵损失曲线

所有曲线通过D3.js的折线图渲染，支持缩放查看训练细节。

### 7.5.3 偏好数据质量统计

展示偏好数据的质量过滤情况：
- 过滤前后偏好对数量对比
- 评分差距分布（chosen − rejected差值分布）
- 语义去重效果（基于嵌入相似度的去重统计）

## 7.6 消融分析视图

消融分析视图集成在统计报告页面中，但作为独立图表区域。展示的数据由`scripts/stage5/visualize_ablation.py`（若存在）或直接从Stage 4的消融实验JSON加载。

消融曲线采用多折线图：X轴为超参数值（如自洽性采样次数N），Y轴为准确率，不同线条表示不同数据集。交互功能包括悬停显示置信区间、点击锁定特定参数组合。

对于二元消融（如是否启用双向评分），使用分组条形图展示准确率差值，并标注相对变化百分比。

## 7.7 远程访问支持

`scripts/stage5/start_local_tunnel_and_api.ps1`脚本实现了以下自动化流程：

1. 通过脚本顶层的 PowerShell `param()` 参数块定义远程主机地址、SSH端口、本地隧道端口和 API 地址等关键配置，修改时无需离开脚本文件。
2. 前台启动 SSH 隧道，将远程服务器的 API 端口映射到本地回环地址。
3. 后台启动 FastAPI 服务器（`run_stage5_api_server.py`），设置 `REMOTE_API_BASE` 环境变量后直接通过 Python 子进程拉起。

远程协助采用SSH隧道实现核心数据传输，结合`scripts/local_sync/rsync_pull.ps1`等脚本从远程服务器拉取实验文件，确保本地可视化平台获取到最新的实验结果文件。
